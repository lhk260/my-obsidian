# 一键论文讲解工作流

## 日常只需要做这些

1. 在 Zotero 中保存论文。
2. 在 Obsidian 运行 `Zotero Integration: Import Notes`，选择论文。
3. 导入后 Source Note 会自动打开；运行 QuickAdd 命令 `论文 → ChatGPT`。
4. ChatGPT 网页打开后按 `Ctrl+V` 并发送。
5. 复制 ChatGPT 输出，回到已经打开的 `<citekey>.ai.md` 粘贴。
6. 关闭 AI 讲解稿，去 `<citekey>.my.md` 用自己的话完成个人笔记。

## 自动完成的内容

- 从 Source Note 的 URL 或 DOI 提取 arXiv ID。
- 生成摘要、HTML 全文和 PDF 全文链接。
- 把阅读前问题和 Zotero 批注加入提示词。
- 创建 `20-Literature/AI-Explanations/<citekey>.ai.md`。
- 创建 `20-Literature/My-Notes/<citekey>.my.md`。
- 回填 Source Note 的两条 Pipeline links。
- 将完整提示词复制到剪贴板。
- 打开 ChatGPT 网页。

## 限制

没有 OpenAI API 时，浏览器登录状态下无法可靠地自动代替你点击“发送”和把回答写回 Obsidian。因此保留两个人工动作：在 ChatGPT 中粘贴发送，以及把回答复制回 AI Explanation。这也是最稳定、最容易排错的方案。
