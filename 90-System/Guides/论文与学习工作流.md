# 论文与学习工作流

## 三层结构

| 层级 | 目录 | 内容 |
|---|---|---|
| Source Note | `20-Literature/Sources` | Zotero 元数据、摘要、原文批注 |
| AI Explanation | `20-Literature/AI-Explanations` | ChatGPT 全文讲解，是中间材料 |
| My Note | `20-Literature/My-Notes` | 自己的判断、研究连接和可执行实验 |

## 每篇论文的最短流程

1. 在 Zotero 保存论文并做必要批注。
2. 在 Obsidian 用 Zotero Integration 导入 Source Note。
3. Source Note 打开时按 `Ctrl + Alt + G`。
4. ChatGPT 网页版中按 `Ctrl + V` 发送提示词。
5. 回答结束后点击回答下方的“复制”按钮。
6. 回到 Obsidian 按 `Ctrl + Alt + V`。
7. AI Note 自动清理并写入；然后关闭 AI Note，完成 My Note。

## 两个快捷键做什么

### `Ctrl + Alt + G`

- 识别 arXiv / DOI / URL；
- 创建 `<citekey>.ai.md` 和 `<citekey>.my.md`；
- 把 Zotero 批注与阅读前问题加入提示词；
- 复制提示词；
- 打开 ChatGPT 网页版；
- 把 Source Note 状态设为 `explaining`。

### `Ctrl + Alt + V`

- 读取剪贴板中的 ChatGPT 回答；
- 去掉全文代码围栏、重复 YAML、使用说明和特殊空格；
- 修复网页复制导致的列表、表格多余空行；
- 覆盖 AI Note 的正文区域；
- 把 AI Note 设为 `complete`；
- 把 Source Note 设为 `explained`。

## 状态规则

只使用一个 `status`，不再组合多个 true/false：

- Source Note：`inbox → explaining → explained`
- AI Explanation：`waiting → complete`
- My Note：`draft → complete → verified`

写完个人笔记后，把 My Note 的 `status` 从 `draft` 改为 `complete`；完成事实核验后改为 `verified`。

## 复制回答的正确方式

使用 ChatGPT 单条回答下方的“复制”按钮，不要在网页上拖选全文。按钮复制的是 Markdown 源格式，表格、公式和列表最可靠。即使回答意外带上 YAML 或代码围栏，`Ctrl + Alt + V` 也会自动清理。

## 原则

- Source Note 只记录来源与证据。
- AI Explanation 可以很长，但不作为自己的最终结论。
- My Note 用自己的语言写，只保留能影响理解、实验或决策的内容。
- 论文工作流不依赖 tag；文件夹、`type` 和 `status` 已足够。
