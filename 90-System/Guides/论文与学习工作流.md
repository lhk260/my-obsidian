# 论文与学习工作流

## 核心原则

每篇需要进入知识库的论文必须经过：

```text
Zotero / PDF
→ Source Note
→ ChatGPT AI Explanation
→ 关闭 AI 稿，独立写 My Note
→ ChatGPT 对照核验
→ Concept / Project / Synthesis
```

三层内容严格分开：

| 层级 | 目录 | 负责回答 |
|---|---|---|
| Source Note | `20-Literature/Sources` | 作者原文写了什么？证据在哪里？ |
| AI Explanation | `20-Literature/AI-Explanations` | 这篇论文如何工作？有哪些事实、推断和待确认项？ |
| My Note | `20-Literature/My-Notes` | 我相信什么、不相信什么？它如何改变我的研究？ |

AI Explanation 可以长；My Note 必须短、可决策，并以自己的语言为主。

## 阶段 1：收集与 Source Note

1. 论文及 PDF 进入 Zotero。
2. 在 Zotero 阅读、高亮并写批注。
3. 在 Obsidian 命令面板运行 **Zotero Integration: Import Notes**。
4. 选择“论文 Source Note”，生成 `20-Literature/Sources/<citekey>.md`。
5. 在 Source Note 的 `Questions before ChatGPT` 写下希望重点解释的问题。

Source Note 不承担长篇总结。黄色高亮记录核心事实，红色记录疑问与缺陷，绿色记录对自己研究的启发。

## 阶段 2：ChatGPT 首次讲解

1. 为研究方向建立 ChatGPT Project，而不是每篇论文建立 Project。
2. 将 [[ChatGPT Project Instructions]] 放进 Project Instructions。
3. 每篇论文单独建立聊天，命名为 `[citekey] 论文简称`。
4. 上传 PDF；必要时上传 supplementary material。
5. 复制 [[Paper AI Explanation Prompt]]，并附上 Source Note 中的红色、绿色批注。
6. 保存输出为 `20-Literature/AI-Explanations/<citekey>.ai.md`。
7. 回到 Source Note，将 `ai_explanation_done` 改为 `true`，补上 AI Explanation 链接。

AI 稿必须把内容分成“原文事实、合理推断、必须查看代码确认”。重要数字找不到页码时，不允许进入 My Note。

## 阶段 3：独立写 My Note

1. 用 `My Paper Note.md` 创建 `20-Literature/My-Notes/<citekey>.my.md`。
2. 补齐 `source` 和 `ai_explanation` 链接。
3. 关闭 AI Explanation。
4. 凭自己的理解先完成：一句话理解、核心问题、核心机制、训练与推理、最关键证据。
5. 再打开 AI 稿补查遗漏，但不要复制其措辞。
6. 写完后将 `summary_done` 改为 `true`。

只有 My Note 可以直接进入项目决策、Concept Note 和多论文综合。

## 阶段 4：ChatGPT 对照核验

把 PDF、AI Explanation、My Note 放回原论文聊天，运行 [[Paper Verification Prompt]]。

检查后：

- 只修改 My Note；
- 对事实错误要求 PDF 页码或图表位置；
- 未确认内容保留为问题，不伪装成结论；
- My Note 确认完成后设 `verified: true`；
- AI Explanation 的 `verified: true` 只表示人工核过，不表示绝对正确。

## 阶段 5：提炼与复习

- 跨论文可复用的机制、公式、边界条件拆成 Concept Note。
- 多篇论文的比较写入 `20-Literature/Syntheses`。
- 项目判断只链接 My Note，不直接链接 AI Explanation。
- 需要整篇复习时给 My Note 添加 `#review`。
- 需要卡片复习时添加 `#flashcards`，用 `Q:: A::` 写主动回忆卡。

## 文件命名

优先统一使用 citation key：

```text
Sources/<citekey>.md
AI-Explanations/<citekey>.ai.md
My-Notes/<citekey>.my.md
```

没有稳定 citation key 时，暂用 `第一作者年份短标题`，不要使用完整论文标题。

## 每篇论文完成标准

- [ ] Source Note 含元数据、PDF/Zotero 链接和原文批注
- [ ] AI Explanation 区分事实、推断和待查代码
- [ ] My Note 是关闭 AI 稿后独立写成
- [ ] 核心 claim 能指向具体实验
- [ ] 已做 ChatGPT 对照核验
- [ ] `summary_done: true`
- [ ] `verified: true`
- [ ] 至少产生一个概念、实验想法、项目判断或写作引用

## 旧笔记如何回填

迁移前已有的个人论文笔记已放在 `20-Literature/My-Notes`，并标记：

```yaml
legacy_import: true
ai_explanation_done: false
verified: false
```

不需要重写它们。依次上传原 PDF 和旧笔记，让 ChatGPT 生成 AI Explanation，再运行对照核验；只修改原 My Note。完成后把 `ai_explanation_done` 和 `verified` 改为 `true`。
