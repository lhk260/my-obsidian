# 论文对照核验提示词

下面有三类材料：

- A：论文 PDF 原文；
- B：你之前生成的 AI Explanation；
- C：我独立写的 My Note。

请以论文 PDF 为最高依据进行对照检查。不要重写完整总结，只输出：

1. My Note 中的事实错误；
2. My Note 遗漏的核心机制；
3. My Note 中缺少证据支持的判断；
4. AI Explanation 自身可能存在的错误；
5. My Note 中比 AI Explanation 更有价值的判断；
6. 建议修改的具体句子；
7. 最值得执行的一个验证实验；
8. 仍然必须检查代码才能确认的问题。

每条必须标记为：

- **原文事实**
- **合理推断**
- **个人研究判断**

如果指出事实错误，请给出 PDF 页码、章节或图表位置。检查后我只修改 My Note，不需要输出一篇新的论文总结。
